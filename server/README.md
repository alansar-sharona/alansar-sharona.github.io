# كود السيرفر (Apps Script) — للتطبيق اليدوي

الملفات هنا **مش بتشتغل من GitHub**. كل ملف `.gs` بيتنسخ كملف جديد جوه مشروع Apps Script بتاع المنصة.
النشر (Deploy ← Manage deployments ← New version) **بموافقة أحمد بس**.

## قاعدة عامة
1. افتح محرر Apps Script ← ➕ Files ← Script، وسمّي الملف بنفس الاسم، والصق المحتوى.
2. زوّد أسماء الدوال الجديدة في قائمة الدوال المسموحة اللي `doPost` بيستخدمها (الماب أو الـ switch اللي بيختار الدالة من `fn`).
3. شغّل دالة الإعداد مرة واحدة من المحرر (Run) ووافق على الصلاحيات.
4. جرّب على النسخة التجريبية (Test deployments) قبل النشر.

## (أ) ساعدني + الإشعارات — `A_Help_Notifications.gs`

**دوال لازم تتضاف لـ doPost:** `helpVideos`, `notifList`, `notifRead`, `contactAdmin`

**الإعداد:** شغّل `setupHelpNotif()` مرة واحدة. بتعمل:
- تاب **الإشعارات**: المعرّف، التاريخ، النوع، الوصف، المستخدم، معرّف_السجل، يحتاج_تأكيد، مقروء_لمين
- تاب **فيديوهات_المساعدة**: معرّف_الموضوع، العنوان، الرابط، الأدوار، الترتيب، مفعّل — متعبّي بكل المواضيع والرابط فاضي
- Trigger كل 10 دقايق لدالة `nxScan` (بتبدأ من اللحظة دي، من غير إشعارات للتاريخ القديم)

**الإشعارات بتطلع منين:**
| الحدث | المصدر |
|---|---|
| بحث جديد مستني اعتماد | كوبو API (من المنصة أو من KoboCollect) — محتاج مفتاح كوبو في Script Properties باسم `KOBO_TOKEN` (لو الاسم عندك مختلف غيّر `NX.KOBO_TOKEN_PROP`) |
| تعديل ملف أسرة / حذف ناعم / رفع صور | تاب سجل_التعديلات |
| عطاء جديد / عطاء اتقفل / تم التوزيع | تاب الأنشطة (بيقارن بآخر مرة) |
| مستخدم جديد | تاب المستخدمين (الاسم والدور بس — من غير PIN) |
| رسالة للمدير | زرار «تواصل مع المدير» في ساعدني |
| شكوى أو اقتراح | الجزء (ب) |

**اختياري (إشعار فوري بدل ما يستنى 10 دقايق):** في أي دالة موجودة تقدر تزود سطر زي:
```js
notify_('تم التوزيع', name + ' — ' + n + ' أسرة', user.name, code, false);
```

**التحقق من الـ PIN:** `nxUser_` بتقرا تاب المستخدمين مباشرة (الأعمدة: الاسم، الدور، فعّال، PIN). لو عندك دالة تحقق جاهزة في السيرفر، بدّل جسم `nxUser_` بيها عشان يبقى فيه مكان واحد.

**ملخص بالإيميل (اقتراح — مش متنفذ):** دالة يومية الساعة 8 الصبح تبعت للمديرين عدد الإشعارات غير المقروءة وأهمها (اللي محتاج تأكيد) بـ `MailApp.sendEmail` من حساب الجمعية. مجاني (الحد 100 إيميل في اليوم). لو موافق أضيفها.

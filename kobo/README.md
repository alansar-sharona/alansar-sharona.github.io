# تعديلات استمارة كوبو (الجزء ج) — **ما تتنشرش غير بموافقة أحمد**

المنصة اتعدّلت خلاص (نفس الأسئلة في `app/index.html` ← `RSPEC`). استمارة كوبو لازم تتعدل بنفس الشكل عشان البحث من KoboCollect يطلع زي البحث من المنصة.
الملف `kobo_form_changes.xlsx` فيه كل سطر محتاج يتضاف أو يتعدل أو يتحذف (تاب survey وتاب choices)، بنفس الأسماء اللي المنصة بتستخدمها.

## الطريقة الأسهل (Formbuilder على kf.kobotoolbox.org)
1. افتح المشروع ← **Form** ← **Edit**. (ما تدوسش Deploy لحد آخر خطوة.)
2. **المنطقة (region):** زوّد اختيارين: `oqda` = «العقدة (5)»، `salam` = «عزبة السلام (6)».
3. **منطقة التوزيع (zone):** زوّد `oqda` = «العقدة» و `salam` = «عزبة السلام»، وفي عمود الفلتر (region) اكتب نفس الكود.
4. **حالة المبنى (bstate):** غيّر label بتاع `bad` لـ «آيل للسقوط»، وزوّد `poor` = «رديء / سيء» قبله. (ما تغيّرش name بتاع `bad` عشان الأبحاث القديمة.)
5. **الأقارب:** احذف `relative_fn` و `relative_rel`، وزوّد `relative_n` (integer) يظهر لما `relative = yes`، وبعد جروب بيانات الأسرة زوّد repeat اسمه `relatives_r` عدده `${relative_n}` وجواه `rel_id` و `rel_rel`.
6. **خانات «أخرى»:** `m_rel_other` (جوه الأفراد)، `appliances_other`، `inc_other_desc` — كل واحدة relevant على اختيار `other` بتاعها.
7. **مرفقات أخرى:** `att_n` (integer من 0 لـ 7) وبعده 7 خانات صور `att_1`…`att_7`، كل واحدة بتظهر لو `att_n` ≥ رقمها.
8. احفظ (**Save**)، وجرّب من **Preview**.
9. **Deploy** بموافقة أحمد بس. بعد النشر: الباحثين يعملوا **Get Blank Form** في KoboCollect عشان ينزلوا النسخة الجديدة.

## بعد النشر
- السيرفر لازم يتحدث (server/C_Form_Regions.gs) عشان يقرا الأقارب الجديدة والمناطق الجديدة وقت الاعتماد.
- الأبحاث القديمة هتفضل شغالة (فيها relative_fn القديم، والسيرفر بيقراه برضه).
